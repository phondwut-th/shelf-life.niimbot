# shared — ข้อมูลกลางของร้าน KACHA

ทุกแอปของร้านอ่านข้อมูลจากที่นี่ ถ้าต้องแก้ข้อมูลร้าน ให้แก้ที่ไฟล์ในโฟลเดอร์นี้ ไม่ต้องไปแก้ในโค้ดของแต่ละแอป

| ไฟล์ | มีอะไร |
|---|---|
| `bases.json` | เบสชา 8 ตัว · อุณหภูมิ/เวลา · ระบบชง 1:25:7.5 · ค่าน้ำ |
| `menu.json` | เมนู 13 ตัว + เกรด · ราคาขาย · สูตรผสมต่อแก้ว (`items`) · สูตรเตรียม (นมผสม/ครีมชีส) · แผนตั้งต้น · ต้นทุนต่อแก้ว |
| `bases.json` → `batch_leaves` | ใบชา (ก.) ต่อเบส 1 ล็อต 1,000 มล. ใช้ id จาก ingredients.json |
| `ingredients.json` | วัตถุดิบ + บรรจุภัณฑ์ (id เดียวกับแอปสต็อก) · ขนาดแพ็ค · ขั้นต่ำ · ราคา · ร้าน |
| `suppliers.json` | ร้านที่สั่งของ · ของถึงกี่วัน (lead_days) · สั่งทุกกี่วัน (cycle_days) |

สูตรตัวจริงอยู่ใน Obsidian vault `~/Desktop/KachaMD` (`สูตรเบสพร้อมขาย_v*` ตัวล่าสุด) ไฟล์ในนี้เป็นสำเนาที่แอปอ่านได้ ถ้าสูตรใน vault เปลี่ยน ต้องตามมาแก้ที่นี่ด้วย

แอปที่อ่านไฟล์เหล่านี้ตอนเปิด: `stock/` (แก้ที่นี่แล้ว publish แอป stock ใหม่ ตัวเลขในแอปจะเปลี่ยนตาม)
